# Diabetes-Prediction-and-Healthcare-Analytics
Diabetes Prediction using Machine Learning with Python and an interactive Power BI dashboard for Healthcare data Analysis and Visualization.

Diabetes Prediction and Healthcare Analytics

## Project Overview
This project focuses on predicting diabetes using Machine Learning classification algorithms and analyzing patient health data through an interactive Power BI dashboard.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Power BI

## Machine Learning Algorithms
- Logistic Regression
- K-Nearest Neighbors
- Decision Tree
- Random Forest

## Model Evaluation
- Accuracy
-Confusuin Matrix
-Classification Report

## Dashboard
Interactive healthcare analytics dashboard showing patient distribution and health-related insights.
